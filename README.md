This is a public repository containing the code used to analyze multispecies planktonic foraminiferal d18O data to estimate thermocline depth. While some data files can be downloaded from a Zenodo repository, other files are too large to upload, including the PMIP4 model simulations (https://esgf.github.io/) and climatology files (https://data.giss.nasa.gov/o18data/grid.html).
